# 章节模型输出协议

本目录持有模型可见的场景归属规则与完整占位示例，供任务单、完整执行合同和窗口修复共同使用。领域持久格式在 shared；模型输出格式在 chapterDetailSchemas，接收后由 evidence/stateClaimBinding 投影。不要在模型侧同时维护场景归属和同一关系的反向 ID 图。

结构化骨架确实会随请求发送。仅检查 system 文本而忽略自动追加的骨架，会误判模型是否看到了必填字段。新骨架必须同时满足严格 schema 和引用关系；示例内容是占位符，不能提供可直接复制的当前正文 ID 或默认剧情决定。

完整合同、任务单与规划修复使用保真接收、严格后校验。原始 JSON 缺字段或图关系错误时，应保留完整响应供已有有界纠正；不能通过自动补事实、丢弃约束或降低质量准入隐藏失败。有效 JSON 与批准进入正文是不同边界。
