# 规划修复建议边界

此模块把暂停中的规划证据转为供新手选择的方向，不批准规划，也不执行修改。HTTP 显式 POST 预约一次建议生成；GET 只读，重启后遗留的运行记录显示不确定，必须用新请求标识明确重试。

- `AdviceSource` 对全量来源、候选和用户意图计算指纹；`AdviceContext` 仅投影允许窗口、相邻只读章节和相关书级约束。摘要缺失必须显式表达，不用付费摘要补齐。大于本地容量上限的输入在调用模型前拒绝。
- `PlanningRepairAdviceService` 保存服务器持有的指导；客户端只能选已有选项。模型判定越界或修改硬约束的选项不可直接恢复。
- 选择沿用 `PlanningRepairRecoveryService` 的预约、来源重验、追加一轮和命令入队。选项拥有稳定恢复标识，客户端换标识不会重复追加。确定的来源冲突可以撤销尚未执行的预约；结果未知时保留预约供明确恢复。
- 建议只发一次结构化请求；禁用传输重试、格式策略切换、备用模型和模型 JSON 修复。300 秒总期限同时传入 AbortSignal。应用重启后的未知结果不自动补跑。
- 建议的完整字段、枚举、列表数量与长度由同一共享 schema 渲染到提示。说明列表最多 8 项，但恢复指导序列化仍限 4000 字符；窗口最多 3 章，不随说明容量放宽。执行合同禁止用静默裁数组或替换诊断值来通过校验。
- `AdviceFailure` 按结构化错误类型生成简短用户提示。确认完整收到但校验拒绝的内容只进入私有 `failureDiagnostics`，不投影到 GET，不成为可采用方案，也不触发第二次模型调用；来源变化时仍遵守 CAS 丢弃迟到保存。历史旧错误记录不在读取时改写。
- 单进程请求锁与数据库 CAS 防止并发提交；该本地部署没有跨进程租约。若部署多 worker，必须先把运行归属升级为持久化租约，不能把其他进程的在途请求判作重启遗留。
