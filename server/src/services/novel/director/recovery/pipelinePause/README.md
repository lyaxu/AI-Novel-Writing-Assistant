# 人工挂起批次的只读投影

导演状态与章节批次可能在恢复命令交接时短暂不一致。`pipelinePause` 仅为公开读取构造等待确认视图：匹配任务与小说归属、批次处于 queued/running 且明确人工挂起、无执行归属或租约、没有在途命令时，覆盖陈旧运行显示。较新的已结束命令不能遮蔽较早的在途命令，读取必须查询本任务全部活跃状态。

已授权规划修复通过持久请求标识与修复键相等证明，且处于可恢复阶段（assessing/repairing/reviewing/ready）、原恢复锚点是章节执行、没有待核实操作或待完成预算授权，才返回继续原授权的节奏板入口；不按错误文案猜测阶段。再次耗尽或结果不确定时仍需源页面新确认，旧授权不能越过门禁。其他暂停保留已有检查点、错误与来源路径。状态读取、规划修复状态接口和小说级概览使用同一公开投影；概览提供源页面导航，执行动作留在节奏板。

此返回对象不能用于数据库写入、乐观锁条件或新增恢复授权。GET 不清除人工挂起、不刷新心跳、不增加预算、不调用模型。恢复写接口必须重新读取真实数据库状态并使用原有幂等与授权检查。
