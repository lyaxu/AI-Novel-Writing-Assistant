# 评估：长文提示词.txt 对本工具的可借鉴性

日期：2026-10-06
文件：`D:\novel\长文提示词.txt`（54,820 字节 / 443 行）
结论：**只有约 15% 可用，且不该整份搬进来。** 大量内容与本项目的产品定位、题材和 AI-first 规则直接冲突。

---

## 一、文件是什么

「三位一体·商业网文创作系统 v2.0」——一份面向**男频爽文**的第三方大模型预设，
把模型当成"AI 代笔人"与用户实时互动（角色扮演式共创）。四条创作法则：
极限铺垫 / 期待感管理 / 连锁震惊反应 / 基因锚定（装逼）。

---

## 二、必须排除的部分（不要借鉴）

### 1. 题材硬编码：男频"装逼"逻辑
`第四法则` 把"繁衍/装逼"写成男频核心基因，女主标准是"处子之身…成为主角的**奖励**"。
本项目面向**新手**、用户实际在写**民俗悬疑/外卖小哥送阴单**（《外卖小道士》）。
把这套搬进来会直接污染所有非男频题材。

### 2. 与 AGENTS.md 直接冲突的两条

| 文件内容 | 冲突点 |
|---|---|
| `写作自主性`：AI 可自主判断推进剧情、引入支线 | AGENTS.md 要求规划可追溯、不得擅自扩展；本项目是"AI 出计划 → 用户确认 → 写作" |
| `互动选项T`：每回合给 ≥3 个玩法选项让用户挑 | 本项目是**自动导演**跑完全书，不存在回合制选选项 |

### 3. 大量固定字符串词表 —— 正是本项目明令禁止的做法
`语言自然化与降重模块` 给出约 45 个"警示词汇"（值得注意的是/综上所述/摩挲/挑眉/深吸一口气…）。
`通用内容限制列表` 又有约 25 个禁用词 + 禁数字/禁衣物细节。
AGENTS.md 的 AI-first 规则：**不得用固定关键词表冒充语义判断**。
本项目已在 `0d5d89ed` 因同类问题删掉过 6 张中文关键词表 —— **不能为了"降重"再引入一批**。

### 4. 明确不适合本项目的硬约束
- 省略号统一为半角 `...`、禁星号、禁拼音 —— 纯格式偏好，与写作能力无关
- 禁止一切外语字符 —— 本项目题材含英文专名时会误伤
- 大量性描写指令 —— 与产品定位无关

## 三、真正值得借鉴的部分（约 15%）

按价值排序：

### ★★★ 1. 黄金开篇五条（最值得吸收）
> 动态场景切入（禁静止开场）、核心冲突前置、避免信息轰炸、限制出场人数、快速展现金手指

对应到本项目：`chapterList` / `chapterWriter` 已有"开篇进入速度""禁环境铺垫"类规则，
但**"限制开篇有名有姓角色不超过三人""金手指须在第 2-3 章内首次兑现"**
这两条目前**没有对应的结构化字段**，值得作为**可选的开篇模板**加进 styleEngine
（数据驱动，不是硬编码进 prompt）。

### ★★ 2. 钩子"九连环"：解一个悬念必须同时埋下一个更大的
> 钩子链式反应：在揭开一个旧悬念的同时，必须埋下至少一个新的、更具吸引力的悬念

本项目有 `inheritedHookResponsibilities`（承接旧钩子）和 `endingHook`（本章留钩子），
但**只管"承接"和"留钩"，没有"解开旧钩时必须同时开新钩"这一条**。
这是一个真实缺口，可加为 `readerExperience` 的规则。

### ★★ 3. 明喻频率控制 + 无意义动作禁令
> 严格控制"好像/似的/如同/仿佛"频率；禁止对非关键部位的无意识摩挲、抚摸

本项目 `forbid-explicit-psychology` 等规则覆盖了"解释型心理"，
但**没有覆盖"高频明喻"和"无意义的小动作填充"**。
后者尤其对症：用户抱怨的"兜兜转转"里，这类描写是主要 contributor。
**注意**：这必须做成**数据驱动的 antiAiRule**（`defaults.ts` 里加一条），
而不是把词表塞进 prompt —— 这样才不违反 AI-first，且用户可按书调整。

### ★ 4. 具体化 vs 抽象
> 避免"赋能""协同""基于XX框架"，改用平实具体的说法

对本项目（AI 味重灾区）有效，但同样应走 antiAiRule 而非硬编码。

### ★ 5. 自检清单三问
> 像真人会这样说话吗？是否过度使用警示词？比喻是否过多、动作是否服务剧情？

可作为 writer prompt 末尾的自检项补充，成本极低。

## 四、建议的落地方式（遵循本项目架构）

| 借鉴项 | 落点 | 形式 |
|---|---|---|
| 黄金开篇 3 条 | `styleEngine/defaults.ts` 或开篇模板 | **数据驱动模板**，按书选择 |
| 钩子九连环 | `chapterAcceptance` / `readerExperience` 规则 | 提示词规则（语义判断交给模型） |
| 明喻频率、无意义小动作 | `DEFAULT_ANTI_AI_RULES` 新增条目 | **数据驱动 antiAiRule**（可按书禁用） |
| 自检三问 | `chapterWriter` 自检段 | 提示词补充 |

**统一原则**：可判定的（有确定词形/结构）→ 做成 `antiAiRule` 数据条目；
需要理解的（钩子承接、是否空转）→ 写进提示词交给模型判断。
**任何情况下都不把大词表直接拼进 prompt。**

---

## 五、明确不做的事

- 不把该文件整体导入为 prompt 资产
- 不引入男频"装逼/女主奖励"类法则
- 不引入回合制互动选项
- 不引入性描写指令
- 不引入格式偏好（半角省略号、禁星号）
