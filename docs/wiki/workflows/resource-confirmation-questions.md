# 资源变化的人工核对

## 判断边界

物品消耗、损坏、丢失、销毁或属于底牌，是故事事件，不是数据入账风险。正文证据明确且归属一致的常规变化可自动记录；高风险、低置信、非法抽取及结构化明确核对问题仍保留人工门禁。

真实风险指归属、持有、证据或账本冲突。模型通过已注册抽取提示返回具体 reviewQuestion、ledgerFact、chapterFact 和 riskReason；两条抽取路径都必须把这些字段保留到提案。已有账本上下文包含持有人和所有者，两者不能混为一谈。

## 展示与操作

源工作区优先展示需要回答的具体问题、已有记录、本章变化与正文证据，持有人/归属类型/状态/限制放在可展开详情。缺少具体旧事实的历史提案不得拼造对比，只说明信息缺失并提供原证据和核对原因。

确认和忽略仍在源工作区，运行记录只读；非法抽取不能直接确认。旧人工暂停/待核对提案不因新规则自动改成已确认，恢复仍需原用户动作。人物解析使用明确身份和绑定别名，歧义或未知所有者不通过子串匹配自动归人。

## 验证边界

离线验证结构字段传递、分类、旧暂停保留和展示文案。实际模型能否持续给出正确、具体且有证据的疑问，以及用户是否容易理解，需要真实模型与UI验收，不能由typecheck替代。
