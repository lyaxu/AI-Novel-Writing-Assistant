# 个人写法与删书任务清理

## 使用个人写法

写法引擎中选择「市井见微·细腻推进」即可试写。正式写书时在小说基础信息选择该书的默认写法；临时试写的选择不等于绑定全书。

定位是普通人视角、生活对白、具体内心声音与有变化的场景。允许轻度粗口，不要求每个人说粗话；放慢关键选择，不慢放所有动作。不是作者文风复刻，也不承诺检测器评分。

配置源为 `docs/style-profiles/shijing-xini.json`。编译 server 后，在 server 目录运行 `node scripts/install-personal-style.cjs` 可安装；脚本按 sourceRefId 查重，重复执行不覆盖 GUI 中的个人修改。数据库目标遵循项目 DATABASE_URL 配置，勿在未知数据库运行。

`characterRules.psychologyMode = situated_inner_voice` 使有效反 AI 规则只禁止重复的抽象情绪解释，允许贴近人物的具体内心推理；`action_only` 明确恢复动作展示优先。未设置时沿用原规则。书、章、任务按同字段优先级继承，不以写法名称或作者名称判断。有效规则用于生成与检测，存储的全局反 AI 规则不改写。

旧写法全部保留；新写法不自动替换所有小说或任务的默认值。

## 删书边界

删除小说的事务按小说 ID 收集所有状态的工作流、助手、流水线和图片任务，不只处理 failed。删除 workflow/agent 时其关联审批、导演命令、步骤等由外键级联处理；流水线和图片任务由删除小说级联处理。

导演 runtime 投影、跟进日志没有小说或任务外键，需要显式删除。只按本次小说及收集到的任务 ID 清理，不能把所有 novelId 为空的记录视为垃圾。小说级无 task 的事件和用量记录也应在身份丢失前清理。

运行记录页继续只读。日常删书从小说列表操作；运行中的创作建议先在来源页面停止再删书，已发往模型的请求无法保证立即停止计费。
