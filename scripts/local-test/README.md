# 本地旧版测试环境启动

仓库根 `start-local.bat` 是当前用户指定的隔离测试入口。固定使用仓库相邻 `.comparison/2026-10-10/old-test.db`、后端127.0.0.1:3000、前端127.0.0.1:5190，并打开原测试书源页。该配置属于本地验收部署，不是产品运行时按书名分支；其他机器需先明确配置自己的数据源，不能默默回退dev.db。

启动使用既有Codex Node24以匹配SQLite驱动，源码直启，显式调用应用startServer；不执行pnpm dev、db push、Prisma全量迁移或种子。数据库缺失、书/任务身份不符、Node/驱动不匹配时停止。冷启动只读检查可运行队列，包括failed副作用任务和creation_studio的暂停兼容例外，避免后台自行执行旧任务。人工暂停始终由源页明确继续。

重复双击通过互斥锁串行处理；服务已存在时核对进程、入口指纹、固定数据库、健康响应及源码新旧，仅复用匹配服务。陌生端口或过期源码拒绝启动，不杀进程、不自动换端口。重载是单独的维护动作，须核对实际进程和无在途调用后执行。日志及PID回执在`.logs/local-test/`，忽略提交；入口修改后须受控重载，不能篡改回执绕过核验。

离线检查：Node24运行`node --test scripts/local-test/startup.test.cjs`。维护验证可运行`start-local.bat -NoBrowser`，执行同一启动逻辑，只跳过自动打开浏览器；这不能替代用户的页面验收。
